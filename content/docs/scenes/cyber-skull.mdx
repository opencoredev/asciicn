## Usage

```tsx
import { CyberSkull } from "@/components/asciicn/cyber-skull";

export function NotFound() {
  return <CyberSkull className="aspect-square w-80" />;
}
```

The skull is a mesh of about 3,200 triangles built in code when the component first draws. The cranium is a shell with sunken eye sockets, a nasal opening, a brow ridge, cheekbones and temples. An upper jaw holds one row of teeth, and a hinged mandible holds the other. Every face goes through a depth buffer, so the jaw, the teeth and the far side of the head hide behind whatever is in front of them from any angle.

`shading` picks what you see. `solid` lights the faces to glyph tones, with the inside of the sockets in shadow and a rim light in `accent`. `wire` draws only the edges the camera can see, as `- / | \` glyphs, plus the outline. `both` lights the faces and draws the sockets, the nose, the jaw and the teeth over them. In Braille and quadrants the edges are drawn as lit dots instead of edge glyphs, so they stay as fine as the rest of the picture.

`surface="faceted"` gives each face one tone, so the low-poly mesh shows. `smooth` blends the light across faces for a rounder bone.

It does not react to hover. Press and drag sideways to turn it and up or down to nod it. Let go mid-drag and it coasts, then settles back to its own spin. With keyboard focus, the arrow keys turn it.

## Notes

- It is announced as an image. Pass `aria-label` to describe what it stands for on your page.
- Under reduced motion it draws one still frame, with the jaw shut, and stays put.
- It draws at up to 60 fps on the CPU and pauses offscreen and in hidden tabs. The mesh is built once and shared by every skull on the page.
- On a touch screen, vertical swipes scroll the page. Sideways swipes turn the skull.
