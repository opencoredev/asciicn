## Usage

```tsx
import { WovenBannerScene } from "@/components/asciicn/scenes/woven-banner-scene";

export function Flag() {
  return (
    <div className="relative h-[520px] overflow-hidden rounded-lg">
      <WovenBannerScene text="HELLO WORLD" className="absolute inset-0" />
    </div>
  );
}
```

The banner is a real piece of cloth. A mesh of 34 by 21 points is held together by three kinds of links: structural links to each neighbour, shear links across each square, and bend links that skip a point so the cloth resists sharp creases. Verlet integration moves the points, eight passes of the links pull them back into shape, and the left edge stays nailed to the pole. Wind pushes on every triangle along its normal and drags along its surface, so the cloth streams out, flaps and folds the way fabric does.

Your `text` is tiled across the cloth in its own coordinates, one line after another, each line shifted three letters on. Letters are attached to the fabric, so they stretch where it stretches, bunch up where it folds, and narrow as it turns away. Where the cloth faces the light the letters show in the thread colour. In dark folds and on the back of the cloth the charset's density ramp takes over, so the folds still read in Braille and blocks, where letters can't be drawn.

Hover to press the cloth like a hand. Drag to grab the nearest point and pull it. Click the sky, or tap the cloth, to send a gust.

## Examples

### Phosphor flag

Braille draws the cloth as lit dots, with the words woven a little brighter than the gaps between them. A mono `phosphor` and some scanlines turn it into a signal flag on an old monitor.

## Notes

- The canvas is `aria-hidden`; it is decoration. If the words matter, put them in the page as text too.
- The cloth is blown for three seconds before the first frame, so a still frame already shows it flying. Under `prefers-reduced-motion` and with `animate={false}` it draws that frame and stops.
- The cloth lives in world space, apart from the glyph grid, so resizing the box or switching charsets keeps its motion. The physics runs in steps of about 1/60 s, up to three a frame.
- Letters are sized to about one glyph cell while the cloth hangs flat, so a bigger box weaves more repeats of the text.
- Buffers are allocated once per grid size, so frames don't allocate them again. At 200 by 60 cells a frame takes about 4 ms with the standard charset and about 7 ms in Braille.
