## Usage

```tsx
import { AsciiGlobe } from "@/components/asciicn/ascii-globe";

const LONDON = [51.51, -0.13] as const;
const TOKYO = [35.68, 139.69] as const;

export function Global() {
  return (
    <AsciiGlobe
      markers={[{ at: LONDON }, { at: TOKYO }]}
      arcs={[{ from: LONDON, to: TOKYO }]}
      className="aspect-square w-full max-w-md"
    />
  );
}
```

Each sample casts a ray at the sphere and reads land from the shared `world-land` mask. The sun, set by `light`, draws a soft terminator. Past it, the land keeps a faint outline so the night side never goes blank. The sea catches a specular glint near the sun, the air thickens at the lit limb, and a thin halo glows outside it. Land above 70° fades to ice.

In truecolor, land takes `color` and sea and air take `oceanColor`. Markers and arcs keep their `accent` in every colour mode, mono included.

The globe stays round and centred and takes 86% of the box's shorter side. Make the box larger than its section and offset it to show only the top, as in the first example.

Drag sideways to spin it and up or down to tilt it. Let go mid-drag and it coasts, then picks its spin back up. On phones a horizontal swipe turns it and a vertical swipe still scrolls the page. With keyboard focus, the arrow keys turn it. Set `draggable={false}` for a globe that only spins on its own.

## Notes

- A draggable globe is focusable and announced as an image labelled "Globe. Drag it or use the arrow keys to turn it." Pass your own `aria-label` to say what it shows.
- Under reduced motion it draws one still frame, markers included.
- It draws at up to 60 fps and pauses offscreen and in hidden tabs. A 600px globe in Braille at 10px cells shades about 58,000 samples per frame.
- Land comes from the `world-land` mask (Natural Earth, public domain), installed with the component. Nothing is fetched at runtime.
