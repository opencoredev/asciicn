## Usage

```tsx
import { TempestStormScene } from "@/components/asciicn/scenes/tempest-storm-scene";

export function Outage() {
  return (
    <section className="relative isolate min-h-[520px]">
      <TempestStormScene className="absolute inset-0 -z-10" />
      <h1 className="text-white">Weathering the storm</h1>
    </section>
  );
}
```

Two decks of cloud roll across the sky, the nearer one shaded by a light above it: where the cloud thins toward the light it is lit, and where more cloud stands in the way it falls into shadow. Lightning strikes at random spots. Each bolt is a jagged channel built by midpoint displacement, with three forks, and it flickers through a first stroke and two return strokes. The strike lights the cloud from inside, lifts the whole sky and outlines the hills on the horizon.

Rain falls in three sheets at different speeds, slanted by the wind. The pointer leans the wind, and a press calls a bolt down onto the pointer. Each press gets its own bolt shape.

Set `strikes` to 0 to leave only the strikes you call yourself.

## Examples

### Green phosphor

In `mono` the storm is carried by glyph density, and the flash shows as a wave of denser glyphs across the sky. `CRT_FX` adds bloom around the bolts. More frequent `strikes` keep it lively.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws the `stillTime` frame and stops. It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen.
- The pointer is read from the window, so it works under overlays and text; the canvas itself never takes pointer events.
- Flashes are brief, but they do brighten the whole sky. Set `flash` lower, or `strikes` to 0, where flashing light could bother readers.
- Bolts are distance fields walked only near the bolt's line; the rest of the screen skips them. Clouds cost three noise lookups per sample. See [Performance](/docs/engine/performance).
