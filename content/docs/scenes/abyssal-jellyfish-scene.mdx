## Usage

```tsx
import { AbyssalJellyfishScene } from "@/components/asciicn/scenes/abyssal-jellyfish-scene";

export function Deep() {
  return (
    <section className="relative isolate min-h-[520px]">
      <AbyssalJellyfishScene className="absolute inset-0 -z-10" />
      <h1 className="text-white">Into the deep</h1>
    </section>
  );
}
```

Each jellyfish swims in surges. Its bell squeezes quickly, which drives it upward, then relaxes slowly while it drifts. The tentacles bend on a travelling wave that grows toward their tips and draw inward while the bell squeezes, like a real stroke dragging them through the water. Bells are translucent, with a bright rim, radial canals and four glowing lobes inside.

Behind them, shafts of light slant down from the surface over a bright caustic net, marine snow sinks in two depths and bubbles climb in wobbling columns. Jellies that swim off the top come back in from below.

The pointer nudges nearby jellies away. A negative `push` draws them toward it instead. `hue` rotates which colour each jelly gets.

## Examples

### Braille tentacles

Braille samples eight dots per glyph, so each tentacle becomes a one-dot thread. Fewer, larger jellies with brighter `tentacles` suit it best.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws the `stillTime` frame and stops. It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen.
- The pointer is read from the window, so it works under overlays and text; the canvas itself never takes pointer events.
- Each jelly costs ten tentacle and arm tests per sample, but only inside its own bounding box, so more `jellies` cost little. Bubbles and snow come from hashed grids. See [Performance](/docs/engine/performance).
