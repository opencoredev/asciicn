## Usage

```tsx
import { FluidSmokeScene } from "@/components/asciicn/scenes/fluid-smoke-scene";

export function Playground() {
  return (
    <div className="relative h-[520px] overflow-hidden rounded-lg">
      <FluidSmokeScene className="absolute inset-0" />
    </div>
  );
}
```

This is a real fluid. A coarse grid of square cells, up to 10,000 of them, runs the stable-fluids method each frame: semi-Lagrangian advection, vorticity confinement to keep small eddies alive, curl-noise turbulence, and 12 Jacobi iterations of a pressure solve that keeps the flow from compressing. Smoke density and temperature ride along with the flow. Heat makes smoke rise, and density picks the glyph.

The grid is sampled with bilinear filtering at the charset's resolution, so Braille draws wisps eight dots to a glyph. Dot charsets default to blue-noise dithering, so thin smoke shows as scattered dots instead of a hard edge.

Move the pointer to stir the air, hold to pour smoke where you drag, and press for a puff that pushes outward.

## Examples

### Incense in your theme

Mono without a phosphor follows `--ascii-ink` and `--ascii-paper`, so the smoke draws in your site's colours in light and dark mode. The dense ramp shades it softly, extra `swirl` curls it, and a higher `fade` keeps it a thin thread.

## Notes

- The canvas is `aria-hidden`; it is decoration.
- The simulation runs about three seconds ahead before the first frame, so a still frame or a fresh resize already shows a plume. Under `prefers-reduced-motion` and with `animate={false}` it draws that frame and stops.
- Steps are fixed at 1/30 s (up to three per frame), so the fluid stays stable at any frame rate. Simulation buffers depend only on the grid size, so switching charsets keeps the smoke.
- A resize restarts the simulation.
