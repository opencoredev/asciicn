## Usage

```tsx
import { DnaHelix } from "@/components/asciicn/dna-helix";

export function Hero() {
  return <DnaHelix className="h-96 w-64" />;
}
```

The two backbones and every rung are built from lit spheres, drawn into a depth buffer one sample at a time. Where a strand swings behind the other, or a rung passes behind a backbone, the nearer surface wins, so the helix stays readable at any angle and in any charset. Braille samples each cell 2×4 times, which gives the finest strands.

The strands sit less than half a turn apart, as in real DNA, which opens a wide groove and a narrow one. Each rung is one base pair: A with T, or G with C. In truecolor each half takes its own base's colour, with a hairline gap in the middle where the pair bonds. The far side of the helix fades towards the paper, and the whole molecule slides slowly along its axis.

Drag sideways to spin it. When it stands upright, drag up or down to tilt it. Let go mid-drag and it keeps spinning, then settles back to its own pace. With keyboard focus, the arrow keys spin and tilt it.

## Notes

- It is announced as an image. Pass `aria-label` to describe what it stands for on your page.
- Under reduced motion it draws one still frame and stays put.
- It draws at up to 60 fps on the CPU and pauses offscreen and in hidden tabs. The cost grows with the number of samples, so a smaller box or a larger `cell` is cheaper.
- On a touch screen, vertical swipes scroll the page. Sideways swipes spin the helix.
