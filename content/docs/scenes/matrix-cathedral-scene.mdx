## Usage

```tsx
import { MatrixCathedralScene } from "@/components/asciicn/scenes/matrix-cathedral-scene";

export function Entrance() {
  return (
    <section className="relative isolate h-[600px]">
      <MatrixCathedralScene className="absolute inset-0 -z-10" />
    </section>
  );
}
```

Every cell casts its own ray into a vaulted nave: rows of round pillars, round arches between them, a barrel vault with ribs at every bay, side aisles and a flagstone floor. Each surface is covered in streams of glyphs that fall down the stone, with a bright head, a fading tail and glyphs that change as you watch. The glyph size steps with distance, so the streams stay crisp as they recede. Far surfaces fade into fog, and a light at the end of the nave warms the stone that faces it.

The camera glides down the nave. Move the pointer to look around; it eases back to centre when the pointer leaves.

## Examples

### CP437 in amber

Any charset becomes the stream alphabet. CP437 rains card suits, arrows and shade blocks, and the `p3` phosphor turns it into one amber ink. A slower `glide` and more streams make it denser.

### One still frame

`animate={false}` draws a single frame at `stillTime`. The `glacier` ramp and thicker `fog` give a cold, deep vault. A still frame costs one draw, so it suits a static header.

## Notes

- The canvas is `aria-hidden`; it is decoration.
- Under `prefers-reduced-motion` and with `animate={false}` it draws one frame at `stillTime`.
- One ray per cell, with analytic hits against planes and cylinders, so cost grows with the cell count, not the scene. 200x60 cells take a few milliseconds a frame.
- Tone-field options (`invert`, `threshold`, `edgeThreshold`, `dither`) are accepted for a uniform scene API but do nothing here. `grade` applies to stream brightness.
