## Usage

```tsx
import { TerminalDeckScene } from "@/components/asciicn/scenes/terminal-deck-scene";

export function StatusWall() {
  return (
    <section className="relative h-[560px] overflow-hidden rounded-lg border">
      <TerminalDeckScene hostname="prod-eu" className="absolute inset-0" />
    </section>
  );
}
```

The deck splits its box into five panes framed with box-drawing rules: a wireframe satellite turning over the limb of a planet, a memory dump that scrolls with live bytes flashing as they change, an oscilloscope whose sweep leaves a fading trail, CPU and memory meters with a load history chart, and a console that types commands and prints their output. Below 90 columns the panes stack into one column and the hex dump drops out when there isn't room. Frames use whole cells only, so they never get cut at the edges.

`charset` draws the two graphical panes: Braille gives single-dot lines, quadrants and the ramps give heavier strokes. The text panes keep their own glyphs whatever the charset.

Drag the satellite to spin it and hover to tilt it toward you. Hover the hex dump to highlight a row.

## Examples

### Amber phosphor

Mono with the `p3` phosphor turns every pane into one amber ink, shaded by brightness. Quadrants draw the satellite and the trace in 2x2 blocks, `frame="double"` swaps the panes to double rules, and a stronger `fx` adds curvature.

### Your own session

`script` replaces the console log with your commands and their output, and `hostname` changes the prompt. `colorMode="ansi16"` with the `xterm` table snaps every colour to the 16 a real terminal has, and `fx={{}}` turns the CRT finish off.

## Notes

- The scene is decorative: the canvas is `aria-hidden`. If the console text matters to your page, put it in real text nearby.
- Under `prefers-reduced-motion` and with `animate={false}` it draws one frame at `stillTime` (6 s, when every pane has content). It pauses offscreen and in background tabs.
- Every frame is computed on the CPU into a Canvas2D grid. Buffers are allocated once per size and reused. At 200x60 cells a frame takes about a millisecond or two to compute.
- The CRT finish is a CSS overlay (`CrtOverlay`), so exports through `handle` capture the glyphs without it.
