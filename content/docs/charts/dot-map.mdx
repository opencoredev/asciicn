## Usage

```tsx
import { DotMap } from "@/components/asciicn/dot-map";

const OFFICES = [
  { at: [51.51, -0.13], label: "London" },
  { at: [35.68, 139.69], label: "Tokyo" },
] as const;

export function Offices() {
  return (
    <DotMap
      markers={OFFICES}
      arcs={[{ from: OFFICES[0].at, to: OFFICES[1].at }]}
      accent="blue"
    />
  );
}
```

The map is text. Land is rasterised onto the 2 by 4 dot grid of Braille glyphs, one dot per sample of a 3.8 KB land mask from Natural Earth's public-domain polygons that installs with it as `world-land`, so nothing is fetched at runtime. `glyphs="halftone"` draws one dot glyph per cell instead (`·`, `•` or `●`, by how much land the cell covers), which reads well at small sizes.

The map fills its container's width in whole cells and keeps the projection's proportions; `cell` sets the glyph size and so the detail. Markers are small blocks of dots with a ring of dots that travels outward and thins as it goes. Arcs are dotted curves drawn on the same dot grid, with a short solid run of light moving along each. `halo` tints the land around each marker, and `regions` draw the land inside a box in a colour of your choice.

Hover a marker, or Tab to it, for a tooltip with its `label` and `detail`.

## Notes

- The map is a labelled group named by `title` plus the marker and region labels. Every marker is a focusable button named by its label and detail.
- Motion runs at 20 frames a second, pauses when the map is offscreen or the tab is hidden, and stops under `prefers-reduced-motion`, leaving the rings at rest.
- The land layer is built once per size and only redrawn when the map's inputs change; only the markers and arcs redraw while animating. Pass `markers`, `arcs` and `regions` as constants or memoised arrays so the land isn't rebuilt each render.
- Land data: [Natural Earth](https://www.naturalearthdata.com/) 1:50m land, public domain, rasterised to 0.75° cells.
