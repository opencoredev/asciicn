## Usage

```tsx
import { AreaChart } from "@/components/asciicn/area-chart";

const data = [
  { month: "Jan", revenue: 18400 },
  { month: "Feb", revenue: 21900 },
  { month: "Mar", revenue: 26300 },
];

export function Revenue() {
  return (
    <AreaChart
      data={data}
      x="month"
      series={[{ label: "Revenue", value: "revenue" }]}
    />
  );
}
```

`data` can hold any objects. `x` names the field with each point's label and every series names the field with its value. Both also accept a function, such as `(datum) => datum.total / 100`, from a Client Component. The chart fills its container's width in whole cells and re-plots when the container resizes.

Each cell column of an area rises in eighth blocks, so its edge is exact to an eighth of a cell. Under the edge the body steps `█ ▓ ▒ ░` toward the axis. AreaChart is a preset of [Cartesian chart](/docs/charts/cartesian-chart).

## Examples

### Stacked, one texture per series

`stack="stacked"` sits each series on the ones before it, and `fill="pattern"` gives each its own texture, so the layers read apart without colour. Where a layer ends part way up a cell, the layer above fills the rest of that cell, so stacks have no gaps.

<ComponentPreview src="examples/area-chart-layered.tsx" size="lg">
  <AreaChartLayered />
</ComponentPreview>

### Compact, in Braille

`axes={false}` and `grid={false}` drop the frame so the area runs to the card's edges. `glyphs="braille"` draws the edge in dots over a body of thinning dots.

## Notes

- The chart is a focusable group labelled with a short summary, and every value sits in a visually hidden table, so screen readers get the data. Arrow keys, Page Up, Page Down, Home and End move the cursor without easing, a polite live region reads the values at each stop, and Escape clears the cursor and any locked series. Legend entries are toggle buttons.
- Colour is never the only signal: each series has its own marker glyph (`● ◆ ■ ▲`), dashes or texture, and the legend and readout show the same key.
- The glyphs render as SVG built from the engine's glyph geometry (`@/lib/ascii/glyphs`), so blocks and shades meet without seams, the chart stays sharp at any zoom, and the server renders it at a default width before the first measurement. Cells snap to whole device pixels and the chart re-plots when its box or the device pixel ratio changes.
- Colours come from the `--ascii-*` tokens: data in `--ascii-color-*` or `--ascii-ink`, axes and labels in `--ascii-ink` mixed toward `--ascii-paper`. The chart follows the theme and the site palette with no JavaScript.
