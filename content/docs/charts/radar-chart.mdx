## Usage

```tsx
import { RadarChart } from "@/components/asciicn/radar-chart";

const axes = ["Reasoning", "Coding", "Math", "Writing", "Vision"] as const;

export function Evals() {
  return (
    <RadarChart
      axes={axes}
      series={[
        { label: "Model v3", values: [86, 91, 78, 72, 64] },
        { label: "Model v2", values: [71, 74, 69, 76, 40] },
      ]}
      max={100}
    />
  );
}
```

Axes run clockwise from 12 o'clock. Rings and spokes are drawn with every other Braille dot, so the grid stays lighter than the data. Each series is an outline one dot wide, traced with Bresenham's line algorithm on the dot grid so there is no blur or anti-aliasing, with its vertices marked by small blocks of dots. `fill` adds a scatter of one dot in four inside each shape; where two shapes overlap the scatter doubles up and reads denser.

Axis labels are real text placed on whole cells around the plot. The chart fills its container up to `size` and replots on resize.

Move the pointer around the chart to read one axis: its spoke lights up, the vertices on it grow, and a tooltip lists every series' value there. Tab to the chart and the arrow keys do the same. Hover a legend row to fade the other series.

## Notes

- The chart is a labelled group with a hidden table of every value by axis and series. Keyboard scrubbing is announced in a live region.
- Series differ by colour and by legend name; the tooltip always names each series next to its value.
- Under `prefers-reduced-motion` the shapes draw at full size with no growth.
- The plot is DOM text in `--ascii-font`, one `<span>` per run of a colour. It renders on the server, stays sharp at any zoom and can be selected and copied.
