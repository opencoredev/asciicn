## Usage

Use `CartesianChart` directly when one chart needs more than one kind of mark: bars with a target line, an area with a forecast line. Each series picks its mark with `type`.

```tsx
import { CartesianChart } from "@/components/asciicn/cartesian-chart";

const data = [
  { month: "Jan", revenue: 38400, plan: 42000 },
  { month: "Feb", revenue: 41900, plan: 44000 },
  { month: "Mar", revenue: 47300, plan: 46000 },
];

export function RevenueVsPlan() {
  return (
    <CartesianChart
      data={data}
      x="month"
      series={[
        { type: "bar", label: "Revenue", value: "revenue" },
        { type: "line", label: "Plan", value: "plan", dashed: true },
      ]}
    />
  );
}
```

`AreaChart`, `LineChart` and `BarChart` are presets of this component with their own defaults. They install it as a dependency, so everything on this page applies to them too.

### How it draws

Everything sits on a grid of glyph cells, `cell` px tall and one font advance wide.

- **Lines** are plotted on a dot grid inside the cells: 2x4 Braille dots with `glyphs="braille"`, 2x2 quadrant blocks with `blocks`. Each step between points is rasterised dot by dot, so curves are four times finer than the text around them. Where two series cross, the one drawn last owns the cell. `ascii` draws lines in `_ - ¯ / \`.
- **Areas and bars** end in an eighth block (`▁▂▃▄▅▆▇`), so a height is exact to an eighth of a cell, over a body that fades `█ ▓ ▒ ░` away from the edge. Horizontal bars end in left eighths (`▏▎▍▌▋▊▉`). With `braille`, bodies are ordered dithering on the dots.
- **Axes** are box drawing (`│ ┤ └ ─ ┬`) and gridlines are dots on the exact quarter-cell row of each tick.
- **Cells shared by two marks** keep both: where a lower layer ends part way up a cell, the layer above fills the rest of it, and a line crossing a bar leaves the bar beneath it.

Missing values (`null`, `NaN`, anything not a finite number) are gaps: lines and areas break there and bars are left out.

## Notes

- The chart is a focusable group labelled with a short summary, and every value sits in a visually hidden table, so screen readers get the data. Arrow keys, Page Up, Page Down, Home and End move the cursor without easing, a polite live region reads the values at each stop, and Escape clears the cursor and any locked series. Legend entries are toggle buttons.
- Colour is never the only signal: each series has its own marker glyph (`● ◆ ■ ▲`), dashes or texture, and the legend and readout show the same key.
- The glyphs render as SVG built from the engine's glyph geometry (`@/lib/ascii/glyphs`), so blocks and shades meet without seams, the chart stays sharp at any zoom, and the server renders it at a default width before the first measurement. Cells snap to whole device pixels and the chart re-plots when its box or the device pixel ratio changes.
- Colours come from the `--ascii-*` tokens: data in `--ascii-color-*` or `--ascii-ink`, axes and labels in `--ascii-ink` mixed toward `--ascii-paper`. The chart follows the theme and the site palette with no JavaScript.
- Scrubbing updates once a frame at most and redraws only when the scrubbed datum changes. The entrance redraws about 24 times.
- The renderer is exported for your own charts: `GlyphFrame` (a grid of glyph cells with an underlay), `GlyphSvg` (draws a frame) and `useCellGrid` (measures a box in cells).
