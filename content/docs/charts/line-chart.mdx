## Usage

```tsx
import { LineChart } from "@/components/asciicn/line-chart";

const data = [
  { time: "12:00", p50: 188, p10: 166, p90: 238 },
  { time: "12:30", p50: 184, p10: 164, p90: 230 },
  { time: "13:00", p50: 191, p10: 167, p90: 245 },
];

export function Latency() {
  return (
    <LineChart
      data={data}
      x="time"
      series={[
        { label: "p50", value: "p50", range: { low: "p10", high: "p90" } },
      ]}
    />
  );
}
```

Every line is plotted on the 2x4 dots of Braille cells and rasterised dot by dot between points, so a curve is four times finer than the text around it. Where two lines cross, the one drawn last owns the cell. LineChart is a preset of [Cartesian chart](/docs/charts/cartesian-chart).

## Examples

### Two periods

`dashed` draws a line in dashes, for a previous period or a target. `markers="all"` puts each series' marker glyph on every point: `●` for the first series, `◆` for the second.

<ComponentPreview src="examples/line-chart-compare.tsx" size="lg">

</ComponentPreview>

### Plain ASCII

`glyphs="ascii"` draws the line in `_ - ¯ / \`, the band in dots and the axes in `| + -`. It reads in any font and copies cleanly into a terminal or a commit message.

## Notes

- The chart is a focusable group labelled with a short summary, and every value sits in a visually hidden table, so screen readers get the data. Arrow keys, Page Up, Page Down, Home and End move the cursor without easing, a polite live region reads the values at each stop, and Escape clears the cursor and any locked series. Legend entries are toggle buttons.
- Colour is never the only signal: each series has its own marker glyph (`● ◆ ■ ▲`), dashes or texture, and the legend and readout show the same key.
- The glyphs render as SVG built from the engine's glyph geometry (`@/lib/ascii/glyphs`), so blocks and shades meet without seams, the chart stays sharp at any zoom, and the server renders it at a default width before the first measurement. Cells snap to whole device pixels and the chart re-plots when its box or the device pixel ratio changes.
- Colours come from the `--ascii-*` tokens: data in `--ascii-color-*` or `--ascii-ink`, axes and labels in `--ascii-ink` mixed toward `--ascii-paper`. The chart follows the theme and the site palette with no JavaScript.
- A gap in the data (a missing or non-numeric value) breaks the line instead of dropping it to zero.
