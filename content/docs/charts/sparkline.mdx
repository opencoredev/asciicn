## Usage

```tsx
import { Sparkline } from "@/components/asciicn/sparkline";

export function Signups() {
  return (
    <Sparkline
      data={[212, 224, 219, 231, 262, 538, 402, 396]}
      label="Daily signups"
    />
  );
}
```

A sparkline is text: one line of glyphs in `--ascii-font` that takes the surrounding font size and sits on the text baseline. By default it draws one eighth block per value (`▁▂▃▅▇`), so eight values take eight characters. Set `width` in cells to fit a column; values are averaged or repeated to fit. The latest value draws at full strength and the rest a step quieter.

## Examples

### Inside a sentence

`glyphs="braille"` packs two values into each character as a line of dots. Both sparklines below are inline text, so they wrap with the paragraph and copy with it.

## Notes

- The glyphs are `aria-hidden`; the sparkline is an image (or, when interactive, a focusable group) whose name summarises the trend in words: first and last value, low and high.
- It is plain text in a `<span>`, so it renders on the server, can be selected and copied, and stays sharp at any zoom. It needs a font with block elements and Braille: the `ascii-tokens` font stack covers both. With `rows` above 1, some fonts leave a hairline between rows of blocks.
- Under reduced motion, or with `animate={false}`, the whole sparkline shows at once.
