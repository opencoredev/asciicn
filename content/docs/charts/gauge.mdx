## Usage

```tsx
import { Gauge } from "@/components/asciicn/gauge";

export function CpuGauge({ load }: { load: number }) {
  return (
    <Gauge
      value={load}
      label="CPU load"
      unit="%"
      thresholds={[
        { value: 70, color: "orange", label: "High" },
        { value: 90, color: "red", label: "Critical" },
      ]}
    />
  );
}
```

The arc is drawn in Braille dots. The track is every other dot in `trackColor`, so it reads as a texture, and the value fills it solid up to the reading. Tick marks are one-dot lines outside the arc, spaced evenly from `min` to `max`. With `indicator="needle"` the arc stays thin and a two-dot line points at the reading instead.

`thresholds` recolour the gauge once the reading passes them, and each one's band shows on the track ahead of time. A threshold's `label` is read out next to the value, so a zone never depends on colour alone.

`variant="linear"` draws one row of eighth blocks (`▏▎▍▌▋▊▉█`) over a shaded track, with tick marks and threshold markers underneath. It fills its container up to `size`, in whole cells.

When `value` changes, the gauge glides to the new reading. On mount it sweeps up from `min`.

## Examples

### Needle dials on a host card

`variant="dial"` sweeps 270°, like a speedometer. These three use `indicator="needle"` and share two thresholds, so Disk reads "Full" in red.

<ComponentPreview src="examples/gauge-dial.tsx">

### Ring beside a summary

`variant="ring"` is a full circle starting at the top, with the reading in the middle and twelve ticks like a clock face. It hides the min and max labels, which would sit on top of each other.

## Notes

- The gauge has `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and an `aria-valuetext` that includes the unit and the threshold label, such as "93%, Full".
- Under `prefers-reduced-motion` the gauge draws at the value with no sweep or glide.
- Every glyph is DOM text in `--ascii-font`, so the gauge renders on the server, stays sharp at any zoom and follows the theme through CSS variables.
