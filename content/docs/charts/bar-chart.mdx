## Usage

```tsx
import { BarChart } from "@/components/asciicn/bar-chart";

const data = [
  { week: "W36", deploys: 61 },
  { week: "W37", deploys: 68 },
  { week: "W38", deploys: 74 },
];

export function Deploys() {
  return (
    <BarChart
      data={data}
      x="week"
      series={[{ label: "Deploys", value: "deploys" }]}
    />
  );
}
```

Each bar ends in an eighth block (`▁▂▃▄▅▆▇`), so its height is exact to an eighth of a cell. Below the cap the body fades `█ ▓ ▒ ░` toward the axis. The highlighted bar, and the one under the cursor, draw solid. BarChart is a preset of [Cartesian chart](/docs/charts/cartesian-chart).

## Examples

### Grouped

With two or more series, bars of one category sit side by side and each series gets its own texture, so the groups read apart without colour.

<ComponentPreview src="examples/bar-chart-grouped.tsx">
  <BarChartGrouped />
</ComponentPreview>

### Stacked

`layout="stacked"` sits each series on the one before it. `highlight="max"` draws the busiest day solid with its total over it.

<ComponentPreview src="examples/bar-chart-stacked.tsx" size="lg">
  <BarChartStacked />
</ComponentPreview>

### Horizontal

`orientation="horizontal"` grows bars to the right in left eighths (`▏▎▍▌▋▊▉`), with category labels on the left and values at the end of each bar. The chart is as tall as its rows; the up and down arrows move the cursor.

## Notes

- The chart is a focusable group labelled with a short summary, and every value sits in a visually hidden table, so screen readers get the data. Arrow keys, Page Up, Page Down, Home and End move the cursor without easing, a polite live region reads the values at each stop, and Escape clears the cursor and any locked series. Legend entries are toggle buttons.
- Colour is never the only signal: each series has its own marker glyph (`● ◆ ■ ▲`), dashes or texture, and the legend and readout show the same key.
- The glyphs render as SVG built from the engine's glyph geometry (`@/lib/ascii/glyphs`), so blocks and shades meet without seams, the chart stays sharp at any zoom, and the server renders it at a default width before the first measurement. Cells snap to whole device pixels and the chart re-plots when its box or the device pixel ratio changes.
- Colours come from the `--ascii-*` tokens: data in `--ascii-color-*` or `--ascii-ink`, axes and labels in `--ascii-ink` mixed toward `--ascii-paper`. The chart follows the theme and the site palette with no JavaScript.
- Negative values hang below the zero line and end in the nearest glyph that fills a cell from the top (`▔`, `▀` or `█`).
