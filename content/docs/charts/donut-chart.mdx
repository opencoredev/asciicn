## Usage

```tsx
import { DonutChart } from "@/components/asciicn/donut-chart";

const data = [
  { label: "North America", value: 48210 },
  { label: "Europe", value: 31870 },
  { label: "Asia Pacific", value: 17430 },
];

export function Regions() {
  return <DonutChart data={data} label="Requests today" />;
}
```

Slices run clockwise from 12 o'clock in the order you pass them. Each takes the next series colour (ink, orange, green, pink, purple, blue, red, grey) unless you set `colors` on the chart or `color` on the slice.

The ring is text. It is rasterised onto the 2 by 4 dot grid of Braille glyphs, so every slice is an exact angular sector and each cell is one character you can select and copy. `glyphs="quadrants"` uses 2 by 2 blocks instead for a heavier, solid look. `gap` cuts a channel of that many dots along each slice boundary.

Hover a slice or its legend row to light it: the others fade, the slice steps out by half a cell, the centre shows its value and share, and a tooltip follows the pointer. Click to keep it lit and press Escape to let go. Tab to the chart and the arrow keys step through the slices.

## Notes

- The chart is a labelled group with a hidden table of every slice's value and share, so screen readers get the numbers, not the glyphs. Arrow-key changes are announced in a live region.
- Colour is never the only cue: the legend, the tooltip and the centre all name the lit slice.
- The sweep runs once, when the chart first scrolls into view. Under `prefers-reduced-motion` the full chart draws at once.
- The glyphs are DOM text in `--ascii-font`, one `<span>` per run of a colour, so the chart renders on the server, stays sharp at any zoom and follows theme changes through CSS variables. A container about 300 cells across redraws in well under a millisecond.
