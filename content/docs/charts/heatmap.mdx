## Usage

```tsx
import { Heatmap } from "@/components/asciicn/heatmap";

const data = [
  { date: "2026-10-10", value: 3 },
  { date: "2026-10-11", value: 0 },
  { date: "2026-10-12", value: 7 },
];

export function Deploys() {
  return <Heatmap data={data} unit={{ one: "deploy", other: "deploys" }} />;
}
```

Each column is a week and each row a weekday. The grid ends with the latest day in `data` and goes back `weeks` weeks, 53 by default. Days missing from `data` count as 0, and entries for the same day add up. Dates are read in UTC, so a square never moves with the visitor's time zone.

Every square is two cells of one level glyph. Values map to `steps` levels; with 4 they draw `░ ▒ ▓ █`, and lower levels also mix the colour toward the paper. Empty days are a faint `··`. When the grid is too wide for its box, squares narrow to one cell, then a calendar drops its oldest weeks and a matrix shrinks its cells.

## Examples

### A year in ASCII

`glyphs="ascii"` draws the levels as `- + * #`. `weekStart={1}` puts Monday on the first row.

### Matrix

`mode="matrix"` draws any grid from `data[row][column]`, labelled by `rows` and `columns`. `glyphs="blocks"` puts a rising eighth block in each square, so a level reads as a height.

## Notes

- The heatmap is a focusable group labelled with a summary (the range, the total and the busiest square). Arrow keys move a `[ ]` cursor between squares, Home and End jump to the first and last, Escape clears it, and a polite live region reads each square's date and value.
- Each level has its own glyph, so the scale reads without colour; colour strength adds a second cue.
- The glyphs render as SVG built from the engine's glyph geometry (`@/lib/ascii/glyphs`), so blocks and shades meet without seams, the chart stays sharp at any zoom, and the server renders it at a default width before the first measurement. Cells snap to whole device pixels and the chart re-plots when its box or the device pixel ratio changes.
