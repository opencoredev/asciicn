## Usage

```tsx
import { Divider } from "@/components/asciicn/divider";

export function Section() {
  return <Divider label="Settings" align="start" />;
}
```

The rule is a run of one glyph, clipped to the width of its container: `─` by default, `━` with `variant="heavy"`, `═` for `double`, `┄` for `dashed` and `-` for plain `ascii`. The pattern variants repeat a short sequence: `dots` is `·`, `beads` alternates `·•` and `diamonds` spaces out `◆`. Patterns start at the label and read outward on both sides, so the glyphs next to the label always match.

`label` sets text into the rule, `──── label ────`. `align="start"` or `"end"` leaves a four-cell lead before it. Without a label, `ornament` sets a single glyph in the middle instead, such as `◆` or `§`.

## Notes

- The root has `role="separator"` and `aria-orientation`. The glyphs are hidden from screen readers; a string `label` becomes the separator's `aria-label`.
- It is plain text with no measuring and no script, so it renders on the server, stays sharp at any zoom and never shifts the layout.
- A run is clipped where the container ends, so the last glyph of a pattern can be cut. Lines (`─━═┄-`) hide the cut.
