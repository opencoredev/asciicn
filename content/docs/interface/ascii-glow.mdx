## Usage

```tsx
import { AsciiGlow } from "@/components/asciicn/ascii-glow";

export function Hero() {
  return (
    <section className="relative isolate overflow-hidden">
      <AsciiGlow position="top" className="absolute inset-0 -z-10" />
      <h1>Light, in characters</h1>
    </section>
  );
}
```

`AsciiGlow` fills its box with glyphs whose density falls off from a point: dense at the centre of the light, sparse at its reach, empty beyond. Ordered dithering between glyph levels (`dither`, Bayer 4×4 by default) smooths the falloff even with a short ramp. Value noise warps the light's edge, and with `drift` on it moves slowly.

In the default `palette` colour mode, faint glyphs are also mixed toward `--ascii-paper`, so the glow softens at its edge as well as thinning out. `mono` draws every glyph in the full colour.

The glow is decorative and fills its box. Size it with `className`, usually `absolute inset-0` inside a `relative` parent, and put it behind your content with `-z-10` in an `isolate` parent.

## Notes

- The glow is `aria-hidden` and lets clicks through.
- It draws on a Canvas2D `AsciiGrid` with the engine's `mapTones`, so it needs no WebGL. It pauses offscreen and in hidden tabs, holds one still frame with reduced motion, and follows theme and palette changes.
- The glow fades in when its first frame is drawn, so server rendering shows the empty box.
- Cost grows with the number of cells. A full-width hero at the default 12 pixel cell is about 8,000 glyphs per frame at 24 fps. Raise `cell`, lower `fps` or set `drift={false}` on slow devices.
