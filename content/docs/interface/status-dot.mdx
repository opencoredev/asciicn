## Usage

```tsx
import { StatusDot } from "@/components/asciicn/status-dot";

export function Presence({ away }: { away: boolean }) {
  return <StatusDot status={away ? "offline" : "online"} />;
}
```

Each state has its own glyph and colour, so the shape tells them apart even without colour:

| Status    | `dot`              | `braille`           | Colour |
| --------- | ------------------ | ------------------- | ------ |
| `online`  | `●`, pings `◉ ◎`   | `⠶`, pulses `⣿`     | green  |
| `busy`    | `◐`, turns `◓ ◑ ◒` | `⣾`, orbits `⣽ ⣻ ⢿` | orange |
| `offline` | `○`, still         | `⠤`, still          | grey   |
| `error`   | `✕`, flashes `×`   | `⣿`, flashes `⠶`    | red    |

`label` replaces the state name next to the glyph, such as `"Degraded"` for a busy service. Set `showLabel={false}` to show the glyph alone; screen readers still hear the label.

## Notes

- The root has `role="status"`, so screen readers announce a new state once, politely. The glyph is hidden from them; they hear the label.
- The animation swaps one glyph a few times a second. It pauses offscreen and in hidden tabs, and with reduced motion each state holds its first glyph.
- The glyph is DOM text in `--ascii-font`, one cell wide, so the label never shifts as it changes.
