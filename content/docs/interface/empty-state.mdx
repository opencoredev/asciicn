## Usage

```tsx
import { EmptyState } from "@/components/asciicn/empty-state";
import { Button } from "@/components/ui/button";

export function NoProjects() {
  return (
    <EmptyState
      illustration="folder"
      title="No projects yet"
      description="Create a project to deploy your first site."
      action={<Button>New project</Button>}
    />
  );
}
```

Each drawing is about 21 cells wide, set as text in `--ascii-font`: line art in the muted text colour, a few accent glyphs in `color`, and a `░` drop shadow down the right and along the bottom, like a dialog in a text-mode interface. The accent glyphs that mean "nothing yet" (the dots above the inbox, the `?` in the lens, the dust in the folder, the gap in the cable) blink in turn.

To draw your own, pass `illustration={{ art, mask }}`: two arrays of strings the same size. In the mask, a space is line art, `a` is accent, `s` is shadow, and `1` to `3` are accent glyphs that blink in that order.

```tsx
<EmptyState
  illustration={{
    art: ["┌───┐", "│ · │", "└───┘"],
    mask: ["     ", "  1  ", "     "],
  }}
  title="Nothing queued"
/>
```

## Notes

- The drawing is `aria-hidden`; the title is a real heading and the description real text. Pick `titleAs` so the heading fits the page outline.
- The art is plain DOM text, so it renders on the server, stays sharp at any zoom and can be selected and copied.
- The blink runs on the Web Animations API, which the browser runs off the main thread. Each glyph stays lit most of the cycle and dims briefly. With reduced motion, or `animate={false}`, every glyph stays lit.
- The four drawings are exported as `EMPTY_STATE_ART` if you want to reuse them elsewhere.
