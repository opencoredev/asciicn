## Usage

Render it from your framework's not-found route. In Next.js that is `app/not-found.tsx`:

```tsx
import Link from "next/link";

import { NotFound } from "@/components/asciicn/not-found";
import { Button } from "@/components/ui/button";

export default function NotFoundPage() {
  return (
    <main className="grid min-h-svh place-items-center">
      <NotFound
        actions={
          <Button asChild>
            <Link href="/">Back to home</Link>
          </Button>
        }
      />
    </main>
  );
}
```

The code is drawn in a 5×7 bitmap face. Each font pixel is two cells of `█` side by side, which makes it square, since a cell is about twice as tall as it is wide. Behind the digits, `depth` steps of `░` (and `·` for a third step) extrude down and to the right. Change the building glyph with `glyph`: `▓`, `#`, `@` or the Braille `⣿` all work.

The scene moves a little. Stars hold still and flare through `+` and `*` now and then, and a row of `▓` passes down the digits every few seconds, like a terminal redrawing.

`path` adds a shell line above the heading, `$ open /blog/2019/launch-week`, with the reply `no such page` and a blinking cursor. Change the reply with `detail`.

## Notes

- The scene is `aria-hidden`. The heading, description and path are real text, so the page reads as "Page not found" and the path, not as rows of blocks.
- The title is an `h1` by default, because a 404 is usually the whole page. Pass `titleAs="h2"` when it sits inside a larger page.
- The scene redraws at 10fps and pauses offscreen and in hidden tabs. With reduced motion it holds one frame with no row lit and the cursor showing.
- At a 14px cell, a three-digit code with the default depth is 46 cells wide, about 320px, so it fits a phone. The scene clips rather than wraps if the container is narrower.
