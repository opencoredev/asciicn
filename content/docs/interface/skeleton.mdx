## Usage

```tsx
import { Skeleton } from "@/components/asciicn/skeleton";

export function PostLoading() {
  return (
    <div aria-busy="true" className="flex flex-col gap-3">
      <span className="sr-only">Loading post</span>
      <Skeleton rows={6} />
      <Skeleton shape="text" lines={3} />
    </div>
  );
}
```

A skeleton is rows of `░` the width of its container. Set the width with a class such as `w-32`; the height is `rows` cells, so it lines up with the glyph grid. `shape="text"` draws `lines` rows with a gap between them and a shorter last line, and `shape="circle"` draws a disc `size` rows across for avatars.

While it waits, a band of `▒▓▒` sweeps from left to right. The band's position comes from the viewport and a shared clock, so the sweep passes over every skeleton on the page as one light rather than each one starting on its own. `motion="pulse"` steps every glyph between `░` and `▒` instead. Swap the glyphs with `chars`, from resting to peak: `"·•●"` makes a dot skeleton, `"⠂⠕⠿"` a Braille one.

## Notes

- Skeletons are `aria-hidden`. Mark the region that is loading with `aria-busy="true"` and give it a short status in text, such as a visually hidden "Loading post".
- The first render, on the server too, is plain rows of the resting glyph, so there is no flash and no layout shift when the sweep starts.
- The sweep redraws at 30fps, writing text straight into each line, and pauses offscreen and in hidden tabs. With reduced motion it holds the resting glyph.
