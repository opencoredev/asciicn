## Usage

```tsx
import { Loader } from "@/components/asciicn/loader";

export function Saving() {
  return <Loader size="sm" color="blue" label="Saving changes" />;
}
```

The default is a one-cell spinner that cycles the `orbit` sequence, `⣾⣽⣻⢿⡿⣟⣯⣷`. Pick another with `spinner`: `braille` (`⠋⠙⠹⠸`), `arc` (`◜◠◝◞`), `tick` (`-\|/`), `bar` (`▁▂▃▄▅▆▇█`) or `quadrant` (`▖▘▝▗`). Other variants are wider:

- `dots`: a bright `●` steps along three dots, leaving a half-lit `•` behind it.
- `wave`: six eighth blocks ride one sine wave, each a step behind its neighbour.
- `comet`: a Braille comet with a full head and a tail of single dots crosses six cells.

Inside a button, pass `color="currentColor"` so the glyphs follow the button's text.

## Notes

- The root is a polite live region (`role="status"`), so a screen reader reads `label` once when the loader appears. The glyphs are `aria-hidden`.
- The width is fixed in cells (1 for a spinner, 3 for dots, 6 for the wave and comet), so text next to it never shifts as frames change.
- Frames are written straight into the text node, only when the glyphs change, with no React render per frame. The loop pauses offscreen and in hidden tabs.
- With reduced motion the loader holds one frame chosen to read as busy on its own: a full orbit glyph, the middle dot lit, a wave crest, the comet mid-flight.
