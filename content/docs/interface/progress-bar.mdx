## Usage

```tsx
import { ProgressBar } from "@/components/asciicn/progress-bar";

export function Upload({ percent }: { percent: number }) {
  return <ProgressBar label="Uploading report.pdf" value={percent} />;
}
```

`value` runs from 0 to `max`, which is 100 unless you set it. The fill is a row of full blocks that ends in one of the eighth blocks `▏▎▍▌▋▊▉`, so 37.5% of a 32-cell bar is exactly 12 cells: `████████████`. The bar is as many whole cells as fit its container, measured in the glyph font, and it measures again when the container or the zoom changes.

Behind the fill runs a track of `░` (`track="shade"`), `·`, `─` or nothing. A new value slides in eighth by eighth over 600ms.

Leave `value` out when you can't measure progress. A comet of `░▒▓█` sweeps the track instead:

```tsx
<ProgressBar label="Indexing repository" />
```

## Examples

### Usage card

`parts` stacks several values in one bar, each in its own colour, with a legend of `█` swatches underneath. Boundaries between parts snap to whole cells, because a cell holds one glyph in one colour. The leading edge of the total keeps its eighth-cell precision.

## Notes

- The root has `role="progressbar"`, is named by the label and reports `aria-valuenow` and `aria-valuetext`. An indeterminate bar leaves the value out, as assistive technology expects. The glyphs are hidden from screen readers.
- The bar is DOM text in `--ascii-font`, one line tall, so it stays sharp at any zoom and its height never changes. Before the first measurement it draws 32 cells.
- With reduced motion, values jump instead of easing and the comet rests in the middle of the track.
- The comet redraws at 30fps and pauses when the bar is offscreen or the tab is hidden.
