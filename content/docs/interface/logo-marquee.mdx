## Usage

```tsx
import { LogoMarquee } from "@/components/asciicn/logo-marquee";

const LOGOS = [
  { alt: "Halcyra", src: "/logos/halcyra.svg", ratio: 163 / 40 },
  { alt: "Quillwork", src: "/logos/quillwork.svg", ratio: 196 / 40 },
  { alt: "Orbitline", src: "/logos/orbitline.svg", ratio: 166 / 40 },
];

export function Customers() {
  return <LogoMarquee logos={LOGOS} label="Customers" />;
}
```

Each logo is drawn into a canvas, area-averaged into a grid of cells `rows` tall and mapped to glyphs. Only the image's alpha counts, so any single-colour SVG or PNG works, and every logo comes out in the same glyph colour whatever its own colours were. With the default `charset="quadrants"`, a 6-row logo is 12 solid sub-cells tall, enough for a mark and a small wordmark at any pixel density. `charset="braille"` gives 24 dots per 6 rows: finer on high-density screens, softer on standard ones. The art is set as text and cached, so a logo used in two marquees is sampled once.

Give each logo its `ratio` (width over height). The marquee then reserves the logo's exact width in cells before the file loads, and the row never jumps.

The row holds two copies of the logos and slides by one copy's width on a loop, so the seam never shows. `speed` is in cells per second. The row pauses while the pointer is over it or a link inside it has focus, and logos turn `--foreground` on hover.

## Notes

- The first copy of the row is a list named by `label`, and each logo is `role="img"` (or a link) named by its `alt`. The second copy only closes the loop, so it is `aria-hidden` and `inert`: its links can't be focused twice.
- The motion is one Web Animations transform on the row, which the browser runs off the main thread. With reduced motion the marquee becomes the still wall.
- Hover and focus pause the row. On touch screens there is no hover, so if the logos are links people need to tap, use `variant="wall"`.
- Logos load with `crossOrigin="anonymous"`; images from another origin need CORS headers to be sampled.
