## Usage

```tsx
import { AsciiBox } from "@/components/asciicn/ascii-box";

export function BuildLog() {
  return (
    <AsciiBox title="build #4182" footer="exit 0" frame="rounded">
      <p>compiled 214 modules in 1.8s</p>
    </AsciiBox>
  );
}
```

`AsciiBox` draws its frame as real box-drawing text in the glyph font (`--ascii-font`): one cell for each corner and each side, in `light` (`┌─┐`), `heavy` (`┏━┓`), `double` (`╔═╗`), `rounded` (`╭─╮`) or `ascii` (`+-+`). The lines run through the middle of the outer cells, so the frame looks the same at any zoom and in any theme.

After it mounts, the box measures its content, rounds its own width and height up to whole cells and pins them, so every glyph of the frame sits on the cell grid and the corners meet the sides exactly. It measures again whenever the content or the space around it changes size. When rounding up would overflow its container, it rounds down instead. Before it measures, and during server rendering, the frame is already drawn and closed.

By default the box is as wide as its content (`w-fit`) and never wider than its container. Pass `className="w-full"` to fill the container. `padding` is in rows, and the columns are doubled, because a glyph cell is about half as wide as it is tall.

`title` and `footer` are set into the borders as text, like `┌─ build #4182 ───┐`. A `title` also names the box as a `group` for screen readers. Long labels are cut short with an ellipsis rather than breaking the frame.

Other props pass through to the wrapping `<div>`. Inside the box, `var(--box-ch)` and `var(--box-cw)` hold the cell height and width, for spacing content on the same grid.

## Notes

- The frame glyphs are `aria-hidden` and can't be selected, so copying the box copies only its content and labels.
- Snapping uses a `ResizeObserver` and a `MutationObserver` on the content. Nothing runs between changes.
- The glyph font needs box-drawing coverage for the frame to join up. The `ascii-tokens` font stack has it.
- `AsciiCard` and other asciicn pieces are built on this box.
