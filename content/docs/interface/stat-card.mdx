## Usage

```tsx
import { StatCard } from "@/components/asciicn/stat-card";

export function Revenue() {
  return (
    <StatCard
      label="Monthly revenue"
      value="$48,210"
      delta={12.4}
      deltaLabel="vs last month"
      trend={[31.2, 34.6, 35.9, 38.7, 43.9, 48.2]}
    />
  );
}
```

The card is a box-drawing frame with the label set into its top edge, like a terminal panel: `╭─ Monthly revenue ──╮`. Inside are the value in large mono figures, the delta, and the trend.

`delta` is a percentage. A positive one reads `▲ 12.4%` and a negative one `▼ 3.1%`. Green means the move is good and red means it is bad; set `good="down"` for metrics such as latency or churn, where falling is good. Zero draws a grey `■`.

`trend` takes recent values, oldest first. They are resampled to the card's width in cells and drawn in the eighth blocks `▁▂▃▄▅▆▇█`. Each row of `trendRows` adds eight levels, so the default two rows show 16.

## Notes

- The label and value are real text. The delta glyph is hidden from screen readers and replaced by the word "Up", "Down" or "No change", so the change doesn't rely on colour or shape alone.
- The sparkline is decorative and `aria-hidden`. If the trend matters, say it in `deltaLabel` or nearby text.
- The frame edges are runs of glyphs clipped to the card, so it follows its content at any width. The sparkline measures its width in cells and redraws when the card resizes.
