## Usage

```tsx
import { GlyphTrail } from "@/components/asciicn/glyph-trail";

export function Hero() {
  return (
    <GlyphTrail className="flex min-h-[480px] items-center justify-center">
      <h1>Your headline</h1>
    </GlyphTrail>
  );
}
```

Move the mouse, a pen or a finger across the box. The pointer lays puffs of glyphs along its path. Each one starts hot, in the densest glyphs of the charset and the `hot` colour, then cools: its glyphs thin out toward the sparse end of the charset, its colour fades to `cool`, and it drifts up and aside on a slow current before it vanishes. The tail frays into wisps while the head stays solid.

Speed sets how much is laid down. A slow move leaves a short, thin line. A quick flick lays hotter, wider puffs, throws a few single-glyph sparks and leaves a long comet behind it.

While nobody draws, a wanderer traces a slow loop across the box and leaves the same trail, so the first frame is never empty. It fades out when the pointer starts drawing and comes back after a few seconds of stillness. Set `idle={false}` for a layer that stays blank until someone touches it.

Children render above the trail. The trail clears itself behind their text and controls, so a headline keeps its contrast while the smoke flows around it. Set `clearContent={false}` to let it pass straight behind. With no children it is a plain layer: place it with `className`, behind or over a section.

```tsx
<section className="relative">
  <YourContent />
  <GlyphTrail className="absolute inset-0 z-10" />
</section>
```

## Notes

- The canvas is decorative and hidden from assistive technology. Children stay in the accessibility tree as usual.
- The canvas has `pointer-events: none`. Moves are read from `window` and kept only when they land inside the box, so links and buttons under or over the trail still work. With no children the wrapper ignores pointer events too.
- Touch is read without blocking scroll: a finger dragging down the page scrolls it and leaves a trail.
- Under reduced motion it draws one still frame of the wanderer's path at `stillTime` and ignores the pointer. With `idle={false}` that frame is empty.
- It pauses offscreen and in hidden tabs. With `idle={false}` the loop stops entirely once the last glyph has burned out, and starts again when the pointer enters the box.
- The tail is drawn translucent, so it fades into whatever is behind the box. On a light page the hottest glyphs deepen instead of paling.
