## Usage

```tsx
import { AsciiFade } from "@/components/asciicn/ascii-fade";

export function Changelog() {
  return (
    <section className="relative max-h-96 overflow-hidden">
      {/* long content */}
      <AsciiFade side="bottom" size={8} />
    </section>
  );
}
```

`AsciiFade` sits on one side of its nearest positioned parent (give the parent `relative`) and draws glyphs in the background colour over the content there. Next to the content the glyphs are sparse, so most of it shows through. Toward the edge they get denser (`░▒▓█` with the default `blocks` set) until the content is gone. The very edge is one solid half cell, so nothing peeks through between glyph rows.

`size` is the depth in cells: rows for `top` and `bottom`, columns for `left` and `right`. `color` is the colour the content fades into, `--ascii-paper` by default. Set it to the parent's background if that differs.

With `drift` on, the inner edge wanders slowly through value noise, so the fade breathes instead of sitting as a flat band.

## Notes

- The fade is `aria-hidden` and lets clicks through to the content under it.
- It draws on a canvas with `AsciiGrid`, so it pauses offscreen and in hidden tabs, holds a still frame with reduced motion, and follows theme changes.
- With `drift={false}` it draws once and again only on resize.
