This also installs [`ascii-box`](/docs/interface/ascii-box), which draws the frame, and [`ascii-glow`](/docs/interface/ascii-glow), which draws the glow.

## Usage

```tsx
import { AsciiCard } from "@/components/asciicn/ascii-card";

export function RuntimeCard() {
  return (
    <AsciiCard title="edge-runtime" footer="31 regions" glow="top-right">
      <p className="font-semibold">Cold starts under 40 ms</p>
    </AsciiCard>
  );
}
```

`AsciiCard` is an `AsciiBox` that fills its container's width, with a `title` set into the top border (`┌─ Title ─────┐`), an optional `footer` in the bottom border and a `description` line above the content. The title also names the card for screen readers.

`glow` lights the inside of the frame with an `AsciiGlow` from an edge, a corner or any point, drawn in the glyphs of `glowCharset`. The glow sits behind the content and fills the cells inside the frame exactly.

Set `interactive` on a card that holds a link or button. Hover or focus inside it turns the frame heavy and brightens the glow.

`AsciiCard` takes every other [`AsciiBox` prop](/docs/interface/ascii-box#props) (`labelAlign`, `shadow`, `filled`, `cell`) and passes the rest to the wrapping `<div>`.

## Notes

- The frame and glow are `aria-hidden`. The card is a `group` named by its title.
- The glow pauses offscreen and in hidden tabs, and holds one still frame with reduced motion.
- The interactive frame swaps glyph sets instantly, as a terminal redraws, with no transition to tune.
- Without `glow`, the card draws no canvas and runs no animation.
