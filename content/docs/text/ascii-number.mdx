## Usage

```tsx
import { AsciiNumber } from "@/components/asciicn/ascii-number";

export function Visitors({ count }: { count: number }) {
  return <AsciiNumber value={count} font="blocks" ghost />;
}
```

`AsciiNumber` formats the value with `Intl.NumberFormat`, then draws each character in a digit face built for the cell grid:

- `blocks`: a 3×5 pixel face with every pixel two cells wide, so pixels come out square. Five rows tall.
- `half`: the same face packed into half blocks (`▀▄█`), two pixel rows per cell. Three rows tall.
- `braille`: the same face with every pixel a 2×2 patch of braille dots. Three rows tall.
- `box`: a seven-segment face in box-drawing glyphs (`┌─┐ ├─┤ └─┘`). Three rows tall.

Every digit in a face is the same width, so columns of numbers line up. Characters a face has no glyph for, such as the letters of compact notation or a currency sign, are set as one plain glyph on the bottom row, like a unit.

When `value` changes, the number counts from what is shown to the new value with an ease-out curve. The box reserves the width of the widest value it passes through, so it never resizes mid-count.

## Notes

- The formatted value is in a visually hidden span for screen readers, and the glyph art is `aria-hidden`. Screen readers read the final value, not the count. Add `aria-live="polite"` to the wrapper if changes should be announced.
- With reduced motion, the number shows its value at once.
- The count runs on `requestAnimationFrame` for `duration` seconds and stops. Nothing runs while the number is still.
- Server rendering draws the `from` value (0 by default) when `animate` is on, and the final value when it is off.
