## Usage

```tsx
import { GlitchText } from "@/components/asciicn/glitch-text";

export function Headline() {
  return (
    <GlitchText as="h2" intensity={0.4} className="text-5xl font-bold">
      Signal lost
    </GlitchText>
  );
}
```

A burst lasts `duration` seconds and steps through a new frame about every 55 ms. Each frame cuts the text into seven horizontal bands at random heights and shifts some of them sideways, swaps a few letters for glyphs from `glyphs`, and pulls two coloured ghosts apart behind the text. A few frames in every burst are clean, so the text flickers rather than smears. When the burst ends, the text is exactly as it was.

`intensity` scales all three at once. At the default 0.35 a burst is a quick twitch: small slips, one or two swapped letters and a thin colour fringe. At 1 the bands jump half a letter or more, close to half the letters turn to blocks, and the ghosts spread wide.

## Notes

- Screen readers get the text once, from a visually hidden copy. The visible layers are `aria-hidden`. Selecting and copying the visible text copies the real string, because swapped glyphs are drawn by CSS pseudo-elements.
- Every effect is a transform, a clip or a pseudo-element, so the text never changes size and nothing around it moves. Slices can reach past the element's edges during a burst; give the parent `overflow: hidden` if that matters.
- With reduced motion there are no bursts: the text shows as is.
- `auto` stops while the text is offscreen or the tab is hidden, and the first burst comes half a second after the text appears.
- No React render per frame. A burst sets styles on its layers directly and stops its timer when it ends.
