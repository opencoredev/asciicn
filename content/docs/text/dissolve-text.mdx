## Usage

```tsx
import { DissolveText } from "@/components/asciicn/dissolve-text";

export function Tagline({ visible }: { visible: boolean }) {
  return (
    <DissolveText as="p" show={visible} order="center">
      Signal resolves out of the noise floor
    </DissolveText>
  );
}
```

Each character climbs a density ramp: empty, then `·░▒▓█`, then its letter. Setting `show` to `false` runs it back down the ramp and away. Characters start `stagger` seconds apart in the `order` you pick and take `duration` seconds each, so a long line reads as a wave of glyphs.

The ramp comes from any engine charset. `braille` fills a cell dot by dot, `quadrants` corner by corner, and the plain ramps (`standard`, `dots`, `petscii`) step through their glyphs. `chars` takes your own ramp from empty to dense.

## Notes

- Letters keep their slots the whole time and the ramp glyphs are painted over them, so the layout never moves while text assembles or dissolves.
- Screen readers get the text from a visually hidden copy while `show` is true, and nothing once it has dissolved. The animated letters are `aria-hidden`.
- The text is invisible until its first assembly, so it never flashes in before animating. With reduced motion it appears (or disappears) at once.
- One `requestAnimationFrame` loop runs during a transition and stops when it ends. React does not re-render per frame.
