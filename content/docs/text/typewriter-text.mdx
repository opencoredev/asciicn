## Usage

```tsx
import { TypewriterText } from "@/components/asciicn/typewriter-text";

export function Install() {
  return (
    <TypewriterText
      as="p"
      prompt="$ "
      phrases={["pnpm add asciicn", "pnpm dev"]}
      className="font-mono"
    />
  );
}
```

Characters land one at a time, `speed` per second on average. `jitter` makes the gaps uneven: a little longer after a space, longer still after punctuation, and now and then a short hesitation. Each finished phrase holds for `pause` seconds, then backspaces at `backspaceSpeed` and the next one starts. After the last phrase it starts over, unless `loop` is `false`.

The cursor is a glyph from the glyph font: `█`, `_` or `▏`. It stays solid while keys land and blinks in steps while it waits, as a terminal cursor does.

## Notes

- Every phrase is laid out invisibly in the same grid cell as the typed line, so the element always takes the size of its longest phrase. Typing and erasing never move the text around it.
- Screen readers get every phrase once, from a visually hidden copy. The typed line is `aria-hidden`, so a screen reader does not read each keystroke.
- With reduced motion nothing types and the cursor does not blink. The text shows in full: the first phrase when `loop` is on, the last phrase when it is off.
- Typing stops while the text is offscreen or the tab is hidden, and carries on from the same character when it comes back.
- Changing `phrases` starts over from the first phrase.
