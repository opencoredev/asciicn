## Usage

```tsx
import { AsciiText } from "@/components/asciicn/ascii-text";

export function Hero() {
  return (
    <AsciiText as="h1" charset="braille" reveal="decode" className="font-bold">
      Ship it
    </AsciiText>
  );
}
```

`AsciiText` draws your text in the element's own font (family, weight and style come from its `className`) into an offscreen canvas at `size` pixels. It averages the coverage of every glyph sample, builds a tone field and maps it to glyphs with the engine's `mapTones`, the same mapping every asciicn renderer uses. The art is a `<pre>` of real characters, so it stays sharp at any zoom and you can select and copy it.

The charset sets the look. `braille` packs 2×4 dots into each cell and gives the smoothest large type. `blocks` and `quadrants` give chunky banners. `standard` and `dense` give classic character art. `edge` traces the letters' outlines with `- / | \`.

## Examples

### Duotone banner

`blocks` with `colorMode="duotone"` colours every glyph by its density along a ramp, here `outrun`. A line break in the text starts a second line.

<ComponentPreview src="examples/ascii-text-banner.tsx" size="md">
  <AsciiTextBanner />
</ComponentPreview>

### Outlines

The `edge` charset runs a Sobel filter over the sampled type and draws a directional glyph wherever the edge is strong. Lower `edgeThreshold` picks up softer edges.

<ComponentPreview src="examples/ascii-text-outline.tsx" size="md">
  <AsciiTextOutline />
</ComponentPreview>

### Reveal on hover

`trigger="hover"` shows the finished art and replays the reveal each time the pointer enters. Here each link wipes in from the left through quadrant glyphs. `fit={false}` keeps every label at the same size.

## Notes

- The real text is always in the element. It shows as plain type during server rendering and until the art is drawn, then becomes visually hidden, so screen readers, search engines and find-in-page read the words while sighted readers see the art. The art itself is `aria-hidden`.
- The art redraws when the element resizes and when web fonts finish loading, so it always uses the font you set.
- With reduced motion, the reveal is skipped and the finished art shows at once.
- Drawing is one canvas pass when the text, size or charset changes. Nothing runs per frame except during a reveal.
