## Usage

```tsx
import { GlyphRain } from "@/components/asciicn/glyph-rain";

export function Hero() {
  return (
    <section className="relative h-[480px]">
      <GlyphRain message="asciicn" className="absolute inset-0" />
      <h1 className="sr-only">asciicn</h1>
    </section>
  );
}
```

Each stream is one column of glyphs with a head and a trail. The head is drawn in `accent`, the cell or two behind it shade from the accent into `color`, and the rest of the trail fades out. Glyphs come from the charset in order of ink: dense ones near the head, faint ones at the tail. Every cell keeps its own glyph, and now and then one changes, so a trail flickers a little as it passes.

Without `message` the rain is ambient: streams start at random columns, fall at different speeds and start again at the top.

With `message`, the text is set in a built-in pixel font and scaled to fill most of the box. Each font pixel covers a whole number of quadrants, so every edge lands on a cell boundary and the letters stay crisp. When a stream's head crosses a cell of the message, that cell fills in behind it: first a dense glyph in the accent, then `░ ▒ ▓`, then a solid block. While the message forms, most new streams fall through its columns, so you watch the letters being written. Cells no stream reaches fill in on their own after a few seconds.

The message holds for `hold` seconds, then wears away cell by cell, faster where a stream passes, and forms again after a short rest. With `loop={false}` it forms once and stays. Trails behind the message are dimmed so the letters read.

The font covers A to Z in both cases, the digits and `! " # & ' ( ) * + , - . / : < = > ? @ [ ] _ |`. Other characters draw as `?`.

## Examples

### Headline over a hero

The message is the headline. Keep it short: four to eight characters fill a hero at any width. Put the same words in a real heading for screen readers.

## Notes

- The canvas is decorative and hidden from assistive technology. Put the message in a real heading too, visible or `sr-only`.
- The first frame already shows the message part written, so it never opens on a blank box.
- Under reduced motion it draws one still frame: the finished message with rain around it. It pauses offscreen and in hidden tabs.
- After a resize the message comes back whole at its new size.
- A message too wide for the box at the smallest size runs off both sides. Use shorter words or a line break on narrow screens.
