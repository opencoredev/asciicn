## Usage

```tsx
import { AsciiMarquee } from "@/components/asciicn/ascii-marquee";

const quotes = [
  { label: "GLYF", value: "182.40", change: 2.41 },
  { label: "BRLL", value: "41.06", change: -0.87 },
];

export function Ticker() {
  return <AsciiMarquee label="MARKETS" status="LIVE" items={quotes} />;
}
```

An item is a string or a quote. A quote draws its `label` in bold, its `value` after it, and its `change` as `▲` or `▼` with the percentage, in `upColor` or `downColor`. A glyph bullet sits between items.

The row repeats the items end to end and moves by exactly one copy's width before it loops, so the seam never shows. With `motion="step"` it moves one glyph cell at a time, like an LED board; `smooth` glides. `speed` is in characters per second either way. `secondRow` adds a row under the first, behind a tee rule, moving the other way.

## Notes

- Screen readers get each item once, as a visually hidden list inside an element with `role="marquee"`. The moving copies and the frame are `aria-hidden`, and changes read as "up 2.41%" rather than as arrow glyphs.
- The motion is a CSS animation on a transform, so it costs no JavaScript per frame. It pauses on hover, while the ticker is offscreen and while the tab is hidden.
- With reduced motion nothing moves. Each row becomes a horizontal scroller, so every item can still be read.
- The row measures one copy of its items after fonts load and again when it resizes, then adds copies until the track is wider than the row.
- The label and the items take the element's text colour; set `color` or a text class on the parent to tint them.
