## Usage

```tsx
import { Matrix } from "@/components/asciicn/matrix";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Matrix className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Every glyph column has its own stream with a random speed and length. The head is the brightest glyph; the tail behind it fades and its characters keep flipping to neighbours on the ramp, each on its own clock. After a pass a column goes quiet for a while, then rolls again whether it rains. A second, slower layer falls behind the first and shows only between near streams.

It draws in `katakana` by default. Heads land at the top of the ramp (digits and `Z`), tails in the katakana. It works in any charset: `standard` and `dense` give a typed rain, `cp437` a DOS one, and `braille` streams of fine dots, two dot-columns per glyph.

In `truecolor` mode, the default, tails fade through tints of `color` and heads take a pale version of it. The far layer stays at the dim end. The default `color` is the theme's green, which is darker in light mode so the rain still reads on white.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows faint vertical streaks in CSS.
- Two layers of a few hash lookups per sample; streams are computed per column, not simulated, so it costs the same at any density. See [Performance](/docs/engine/performance).
