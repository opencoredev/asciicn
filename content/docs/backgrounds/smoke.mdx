## Usage

```tsx
import { Smoke } from "@/components/asciicn/smoke";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Smoke className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Rising, curling noise gives the billows; a slow warp curls the plumes as they climb. The smoke is thick at the bottom and thins out towards `height`, and its top edge follows the plumes so it never reads as a straight line. Smoke that thins towards the upper left is lit, the far side of a billow sits in shadow, and the lit edge of each billow gets one glyph step brighter so its outline reads.

It draws in the `standard` ramp (` .:-=+*#%@`) by default. With `interaction="trail"`, the default, the pointer leaves a fading wake through the smoke.

In `palette` mode, the default, tone runs from `shadowColor` up to `ink`. In `truecolor` mode colour follows the light instead, so the shadowed side of a dense billow stays dark.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a soft CSS haze rising from the bottom.
- The smoke samples its noise twice per glyph sample, once for density and once for the light. See [Performance](/docs/engine/performance).
