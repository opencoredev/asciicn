## Usage

```tsx
import { Halftone } from "@/components/asciicn/halftone";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Halftone className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Each dot sits on a screen turned by `angle`, `pitch` glyph rows apart, and takes one value from the source at its centre, as in print. Its radius grows with that value. The screen slides slowly along its angle, so dots swell and shrink as they cross the source.

The `braille` charset is the default, so each dot is a crisp disc built from 2×4 sub-dots. With `dots`, each one comes out as a cluster of glyphs, `●` in the middle and `·` round the edge, and `blocks` gives square, poster-like dots. With `pitch` below 1.5 every glyph becomes its own dot and the screen angle no longer applies.

`source` picks what drives the dot size: `"noise"` for drifting clouds, `"radial"` for a spot that fades out from `center`, or `"linear"` for a ramp towards `direction`. Pass `channels` with two or three inks for separate screens, each turned 30° from the last. In `truecolor` mode, the default, each channel keeps its own ink and overlapping dots blend.

## Examples

### Three-ink print

Three `channels` at 15°, 45° and 75° on a pitch of 4 rows. Where the screens cross, the inks blend.

### Spotlight from below

A `radial` source centred below the box with a short `radius` lights only the bottom edge. The `dots` charset draws each dot as a cluster of `●` and `•`, and `background="transparent"` lets the page show between them.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows rotated CSS dot screens in the same inks.
- Each extra channel samples the source again, so three channels cost about three times one. See [Performance](/docs/engine/performance).
