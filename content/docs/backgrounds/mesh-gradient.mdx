## Usage

```tsx
import { MeshGradient } from "@/components/asciicn/mesh-gradient";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <MeshGradient className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Each blob drifts on its own slow loop, and a soft noise warp bends their edges. Two things come out of them: how dense the glyphs are, highest in the cores, and which colour they take, blended between the blobs that overlap there. `contrast` sets how much the density follows the blobs; at 0 the glyphs are even and only the colour moves.

The `dots` charset is the default: the cores fill with `●` and the seams thin out to `·`, like coloured ink on newsprint. `standard` gives a typed look, and `blocks` fills the cores with `█`.

Colour carries this piece, so `truecolor` is the default. Blob `i` takes `colors[i]`. In `palette` mode the colours are read by density instead, and in `mono` mode only the glyph density moves.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows blurred CSS gradients in the blob colours.
- It costs one GPU pass per frame at 30 fps. See [Performance](/docs/engine/performance).
