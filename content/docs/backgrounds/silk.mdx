## Usage

```tsx
import { Silk } from "@/components/asciicn/silk";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Silk className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The cloth is a height field of folds bent by slow waves, lit from the top left. Faces turned to the light take the densest glyphs, the far side of each fold falls through the ramp into shadow, and a narrow highlight runs along every crest. Steep sides get a thin rim, so each fold reads as an edge of glyphs rather than a blur.

It draws in `blocks` by default (` ░▒▓█`), which suits the long soft gradients of cloth. `quadrants` gives a finer, crisper weave and `standard` a typed look.

The default `palette` mode colours glyphs by tone: paper, a tint of `shadeColor`, a tint of `ink`, then `ink`. In `truecolor` mode colour follows how squarely the cloth faces the light instead, so shadowed folds turn to `shadeColor` even where they are dense.

## Examples

### Behind a headline

Fewer `folds`, a sharper `sheen` and an `intensity` of 0.45 keep the brightest crest in the middle of the ramp, so the text on top stays readable.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows soft diagonal sheens in CSS in the same colours.
- The cloth is lit from three height samples per glyph sample; `braille` samples eight times per cell. See [Performance](/docs/engine/performance).
