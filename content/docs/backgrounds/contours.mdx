## Usage

```tsx
import { Contours } from "@/components/asciicn/contours";

export function Section() {
  return (
    <section className="relative isolate min-h-[420px]">
      <Contours className="absolute inset-0 -z-10" />
      <h2>Your heading</h2>
    </section>
  );
}
```

The hills are smooth noise that drifts slowly. `lines` sets how many contour lines run from the lowest ground to the highest, and every `index`th line is drawn heavier, as on a survey map. `relief` shades the slopes that face away from a light in the top left, so the hills read between the lines.

The `braille` charset is the default: each glyph holds 2×4 dots, so a line one sample wide is a single trail of dots and index lines, drawn wider, come out as a double trail. `weight` sets the line width in samples. Ramp charsets such as `standard` draw ordinary lines at mid tone and index lines in the densest glyphs, like a heavier pen; give them a `weight` of 2 or more so the lines stay unbroken.

In `palette` mode, the default, ordinary lines take `lineColor` and index lines take `ink`. In `truecolor` mode the colour follows height instead, from `lineColor` in the valleys to `ink` on the peaks.

## Examples

### Quiet behind a headline

Fewer lines, no index lines and no relief keep it calm. Two soft tints of the ink as `lineColor` and `ink` leave the text the strongest thing on the page.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows faint CSS rings in the same colours.
- Each sample reads the terrain three times to measure its slope. It stays one GPU pass per frame. See [Performance](/docs/engine/performance).
