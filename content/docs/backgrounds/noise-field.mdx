## Usage

```tsx
import { NoiseField } from "@/components/asciicn/noise-field";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <NoiseField className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The texture is fractal noise folded back on itself by `warp`, drifting along `angle` at `flow`. `variant` changes its shape:

| Variant    | Shape                                         |
| ---------- | --------------------------------------------- |
| `smoke`    | Soft folds that shade from sparse to dense    |
| `ridges`   | Sharp creases, like crumpled paper            |
| `contours` | Topographic lines, `bands` per unit of height |
| `marble`   | Warped stripes, `bands` across the box        |

`detail` adds octaves of finer noise, `contrast` hardens the edges, and `coverage` shifts how much of the box is inked. `mask` fades the field out where text sits.

The `standard` charset is the default, shading each fold from `.` to `@`. `dense` gives a finer, busier texture, and `braille` turns it into crisp islands of dots. In `palette` mode, the default, `highlight` takes the brightest peaks. In `truecolor` mode the warp swirls between `ink` and `highlight` instead, like marbled paper.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows two soft CSS clouds, masked the same way.
- Each sample costs about three times `detail` noise calls. Lower `detail` on large boxes or slow devices. See [Performance](/docs/engine/performance).
