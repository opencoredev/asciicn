## Usage

```tsx
import { Ripples } from "@/components/asciicn/ripples";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Ripples className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Each source sends out a train of rings that fade with distance. A crest has a bright core and a dimmer shoulder on either side, so it reads as a line with a soft edge. Where crests from two sources cross they add up to the densest glyphs. A slow swell bends every ring a little, as on real water.

It draws in `braille` by default, so each ring is a line of fine dots. With `interaction="ripple"`, the default, a click or tap sends a ring out from the pointer on top of the field's own.

In `palette` mode, the default, tone runs from `secondColor` up to `ink`. In `truecolor` mode the first source keeps `ink` and the other sources take `secondColor`, so you can tell the rings apart where they cross.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows rings around each source in CSS.
- Each source adds one distance and one cosine per sample, so four sources cost about the same as one. See [Performance](/docs/engine/performance).
