## Usage

```tsx
import { Ridgelines } from "@/components/asciicn/ridgelines";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Ridgelines className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The lines run back to front, flat at the ends and peaked in a band in the middle, `spread` wide. Each one fills the space under it with paper, so it hides the lines behind, and `shade` adds a faint tone under the tallest peaks so they read as solid. A short box draws fewer lines, keeping at least four and a half samples between them.

The `braille` charset is the default: each line is one row of dots, so up to 64 lines stay separate. `quadrants` and `standard` give heavier strokes.

In `palette` mode, the default, every line takes `ink`. In `truecolor` mode the back lines take `farColor` and the colour shifts to `ink` towards the front.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows thin CSS lines across the box.
- Each sample only evaluates the few lines that can reach it, so 64 lines cost little more than 16. See [Performance](/docs/engine/performance).
