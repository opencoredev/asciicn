## Usage

```tsx
import { AsciiGradient } from "@/components/asciicn/ascii-gradient";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <AsciiGradient angle={160} className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The gradient fills its box, so give it a size with `className`. It runs from paper at the start to ink at the end, in your theme's `--ascii-paper` and `--ascii-ink` colours.

## Examples

### Glow behind a headline

A radial gradient that starts as ink and fades to paper. With the centre below the bottom edge and a small radius, only a low arc of light shows, and the headline sits on clean paper.

### Conic sweep through a palette

`palette` takes any number of colours from paper to ink. A conic sweep jumps from its last colour back to its first, so this palette starts and ends on the background to hide the seam. Blue noise gives it an even, grainy texture.

<ComponentPreview

### Still, inside a card

With `animate={false}` the gradient draws one frame and stops. `to={0.55}` keeps the densest band light enough for text to sit on, and setting `--ascii-paper` to the card's own background blends the gradient into it.

## Notes

- The gradient is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a smooth CSS gradient in the same colours.
- One gradient costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/engine/performance).
