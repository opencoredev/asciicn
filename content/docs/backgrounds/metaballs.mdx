## Usage

```tsx
import { Metaballs } from "@/components/asciicn/metaballs";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Metaballs className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Each blob rises and sinks on its own slow loop. Where two come close their fields add up and they flow into one shape, then pull apart again. In a tall box the blobs are sized by the width, so they still fit.

`variant="solid"`, the default, fills each blob densest at its core and draws a bright rim along the edge, with a faint halo outside. `variant="rings"` draws contour lines around the blobs instead, which ripple outwards over time.

The `blocks` charset is the default: the rim is a line of `█` and each blob shades inwards from `▒` to `█`, with a `░` halo outside. `standard` shades with `+`, `#` and `@`, `quadrants` and `braille` draw flat, smooth-edged shapes, and `braille` suits the rings.

In `truecolor` mode each blob takes the next entry of `colors`, and merging blobs blend. In `palette` mode, the default, the glyphs take `colors` by tone.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows soft CSS blobs in the first colour.
- Each sample adds up every blob, so more `count` costs more. `rings` samples three times to find the line width. See [Performance](/docs/engine/performance).
