## Usage

```tsx
import { Waves } from "@/components/asciicn/waves";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Waves className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The `ocean` variant stacks swells from the horizon down to the viewer. Far swells are flat and close together, near ones tall and slow. Each crest is a line of the densest glyphs whose brightness wanders along its length like foam, over the dimmer body of its swell. The sky glows just above the horizon.

The `lines` variant draws thin lines that swell in the middle and taper at both ends. It switches the default charset to `braille`, so every line is a row of fine dots.

The ocean draws in the `standard` ramp. In `truecolor` mode, the default, near crests take `ink` and far swells and the horizon fade to `farColor`.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS horizon and swell lines.
- Each sample checks every layer, up to eight. See [Performance](/docs/engine/performance).
