## Usage

```tsx
import { Tunnel } from "@/components/asciicn/tunnel";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Tunnel className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Depth goes as one over the distance from the vanishing point, so equal steps in depth bunch up towards the centre and the rings grow as they pass. Spokes run along the walls and every other panel between rings and spokes is lit, like tiles. Far away the rings crowd closer than a glyph, so they fade into the fog. Line widths are measured in sample rows, so a ring stays at least one glyph thick at any size.

It draws in the `standard` ramp by default. `quadrants` gives thinner lines, `petscii` a home-computer look.

In `truecolor` mode, the default, the rings change colour as they near: `farColor` deep in the tunnel, `ink` up close.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows concentric CSS rings.
- One square root and one arctangent per sample. See [Performance](/docs/engine/performance).
