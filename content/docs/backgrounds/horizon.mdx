## Usage

```tsx
import { Horizon } from "@/components/asciicn/horizon";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Horizon className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The planet is a dark arc whose top sits at `horizon`, measured up from the bottom. `curve` sets how round it is, from almost flat to a small globe. Above it, a glow drifts sideways, broken into curtains by `aurora`, and stars scatter across the sky, thinning out near the glow.

The `standard` charset is the default, with the rim drawn in the densest glyphs. `dense` softens the glow, and `braille` turns the stars into single dots.

In `truecolor` mode, the default, the rim and the low glow take `ink` and the glow cools to `hazeColor` as it rises.

### Under a headline

A low, round planet leaves the top of the box for text. More `stars` fill the empty sky.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS glow over a dark arc.
- It costs one GPU pass per frame at 30 fps. See [Performance](/docs/engine/performance).
