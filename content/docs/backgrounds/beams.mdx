## Usage

```tsx
import { Beams } from "@/components/asciicn/beams";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Beams className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The light starts at `origin`, a point given as fractions of the box from the top left. It can sit outside the box: just above the frame for a spotlight, or far away for near-parallel shafts. `angle` points the cone like a CSS angle (180 is straight down) and `spread` sets its width.

Each shaft has a firm edge, so the glyph ramp shows separate rays rather than a grey wash. The `standard` charset is the default; `dense` gives the shafts a finer grain, `braille` turns them into needles of dots, and `blocks` into solid bars.

In `palette` mode, the default, bright glyphs take `ink` and dim ones fade towards `paper`. In `truecolor` mode the colour follows distance instead: `ink` near the source, `farColor` where the light runs out.

## Examples

### Spotlight over a headline

An origin just above the top edge and a narrow `spread` make a stage spotlight. `reach` stops the light before it reaches the text, and `farColor` cools the far end of each ray.

<ComponentPreview src="examples/beams-headline.tsx" size="lg" align="stretch">

### Through a high window

An origin far above the box gives near-parallel shafts. `phosphor="p3"` in `mono` mode and an `fx` bloom put it on an amber terminal.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a soft CSS cone in the same colours.
- It costs one GPU pass per frame at 30 fps. See [Performance](/docs/engine/performance).
