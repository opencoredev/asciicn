## Usage

```tsx
import { Eclipse } from "@/components/asciicn/eclipse";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Eclipse className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The disc is the paper colour, so it reads as a hole in the glyphs. A thin rim runs round it, brightest on the side `light` points to, and the corona reaches out by `corona`, broken into spokes by `streamers`. `pulse` lets the whole glow breathe.

It uses the `standard` charset by default, so the corona falls off from `@` at the rim through `#`, `+` and `:` to `.` at its edge. `dense` gives a finer, busier halo, and `braille` shows the streamers as sharp spikes of dots.

In `truecolor` mode, the default, the rim takes `rimColor`, which runs hotter than the corona by default, and the corona takes `ink`. In `mono` mode everything takes `ink` or a `phosphor`.

## Examples

### Beside a headline

Moving `center` to the upper right leaves room for text on the left. `light` at 225° turns the hottest part of the rim towards the copy below it.

### Amber terminal

`phosphor="p3"` in `mono` mode, the `cp437` charset and full `streamers` give a long, ragged corona, with an `fx` bloom on top.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS disc inside a soft ring.
- Samples inside the disc return early, so a large disc costs less. See [Performance](/docs/engine/performance).
