## Usage

```tsx
import { Plasma } from "@/components/asciicn/plasma";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Plasma className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Four sine waves, one of them circling, add up into blobs that flow into each other. A slow noise `warp` bends the pattern so it never looks mechanical. `bands` sets how many times the tones cycle across one wave, and `crest` sharpens the top of each band so the densest glyphs gather in clear ridges with open troughs between.

The `standard` charset is the default, so each crest builds from `.` and `:` up to `#` and `@`. `blocks` gives the `░▒▓█` plasma of DOS demos, `dense` a finer typed texture, and `petscii` a Commodore one.

In `truecolor` mode, the default, the hue follows the wave phase and walks through `colors` and back, so neighbouring bands always share a colour edge. In `duotone` mode the tone runs through a `ramp`; in `ansi16` mode colours snap to the 16 ANSI colours.

## Examples

### Behind a headline

Capped at 30% `intensity`, the glyphs stay light enough that the headline wins. A larger `warp` and smaller `scale` give broad, slow shapes.

### Duotone ramp

`colorMode="duotone"` with `ramp="outrun"` reads the tone through a named ramp from deep violet to gold, in `dense` glyphs.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows soft CSS blobs in the first and last colours.
- It costs one GPU pass per frame at 30 fps. See [Performance](/docs/engine/performance).
