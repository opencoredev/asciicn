## Usage

```tsx
import { Starfield } from "@/components/asciicn/starfield";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Starfield className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Stars sit on three grids of different sizes that drift at different speeds, so the near layer slides past the far ones. Each grid square holds at most one star, so stars never clump. A star is exactly one sample: one glyph in a ramp charset, one dot in `braille`. The brightest stars get a small cross of dimmer glyphs around them, and a faint haze drifts behind.

It draws in halftone `dots` (` ·•●`) by default, so faint stars are specks and bright ones are full discs. `braille` makes a fine dusting of single dots.

In `truecolor` mode, the default, each star takes its own temperature from cool blue to warm around `ink`, set by `temperature`. The haze takes `hazeColor`.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame at `stillTime` and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows tiled CSS dots in the star colours.
- Three hash lookups per sample; it is one of the cheapest backgrounds. See [Performance](/docs/engine/performance).
