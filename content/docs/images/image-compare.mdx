## Usage

```tsx
import { ImageCompare } from "@/components/asciicn/image-compare";

export function BeforeAfter() {
  return (
    <ImageCompare
      src="/photos/harbour.jpg"
      alt="The harbour at night, as glyphs and as a photo"
      charset="braille"
      className="aspect-video w-full"
    />
  );
}
```

The left side draws glyphs in the look you pass, with the same props as [ASCII image](/docs/images/ascii-image). The right side is the original file. Pass `against` with a second look to compare two looks instead, such as a charset against another charset.

Drag anywhere on the image to move the divider. The divider moves without re-rendering React, so both sides keep their frame rate while you drag. On touch screens a vertical swipe still scrolls the page.

## Notes

- The divider is a `slider` with a visible focus ring. Arrow keys move it 2%, Page Up and Page Down 10%, Home and End jump to the edges. Screen readers hear the share given to the left side.
- The whole comparison is a group labelled with `alt`. The canvases inside are hidden from assistive technology.
- Both sides sample the image once and redraw only when a prop or the size changes. Nothing animates, so there is no frame loop to pause.
