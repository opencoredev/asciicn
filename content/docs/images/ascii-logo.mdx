## Usage

```tsx
import { AsciiLogo } from "@/components/asciicn/ascii-logo";

export function Brand() {
  return (
    <AsciiLogo
      src="/brand/wordmark.svg"
      alt="Acme"
      effect="shimmer"
      className="h-16"
    />
  );
}
```

The logo's coverage decides where glyphs go: a transparent pixel stays empty and a solid one draws the densest glyph. Braille is the default because its 2×4 dots per cell keep letterforms readable down to small sizes. `charset="edge"` outlines the shapes with `- / | \` strokes.

Give the logo a height (or a width) and it keeps the file's own aspect ratio once it loads. Pass `ratio` to reserve the space before then. Without `cell`, the cell is about a tenth of the logo's height.

For a dark logo on an opaque white background, such as a JPEG, set `source="dark"`. `tone="original"` keeps the file's own colours.

## Notes

- The wrapper is announced as an image named by `alt`. Inside a link that already names the brand, pass `alt=""`.
- Effects stop under reduced motion, and the logo draws once. They also pause offscreen and in hidden tabs.
- A logo with no effect draws once per size or prop change and runs no frame loop.
