## Usage

```tsx
import { AsciiDonut } from "@/components/asciicn/ascii-donut";

export function Spinner() {
  return <AsciiDonut className="aspect-square w-80" />;
}
```

Every sample casts a ray from a perspective camera and marches it into the torus, so the silhouette, the hole and the near side overlapping the far side are exact at any cell size. Braille and quadrants sample 2×4 and 2×2 times per cell, which sharpens the outline further.

The shading is built for glyphs. A key light sets the body tone, a cool rim light from behind outlines the far edge, the inside of the ring sits in soft shadow, and a tight specular highlight is the only place the densest glyphs appear. In truecolor, the body takes `color`, the rim takes `rim`, and highlights go white.

Drag to spin it. Let go mid-drag and it coasts, then settles back into its own spin. With keyboard focus, the arrow keys turn it.

## Notes

- It is announced as an image. Pass `aria-label` to describe what it stands for on your page.
- Under reduced motion it draws one still frame. Dragging and the arrow keys still turn it.
- It draws at up to 60 fps and pauses offscreen and in hidden tabs. Rays that miss the ring's bounding sphere skip the march, so empty space costs almost nothing.
