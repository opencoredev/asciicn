## Usage

```tsx
import { AsciiOrb } from "@/components/asciicn/ascii-orb";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <AsciiOrb color="purple" className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The orb is a sphere shaded by one light, with a soft terminator, a thin rim light on the shadow side and a dithered glow that falls off around it. Its outline breathes with two slow harmonics and a little noise (`morph`). When the pointer moves anywhere on the page, the orb and its light ease towards it, then drift back to the centre when the pointer leaves.

Pass `highlight` for a third, brighter tone on the specular spot, such as `"#fff"` or a pale mix of the orb colour. Pick a colour that is light in both themes: `"--foreground"` turns black in light mode.

## Notes

- The orb is decorative and hidden from assistive technology.
- With reduced motion turned on, it draws one still, centred frame and ignores the pointer.
- One WebGL context per orb. It pauses offscreen and in hidden tabs, and the pointer listener is passive and eased in one animation frame loop that stops once the orb settles.
