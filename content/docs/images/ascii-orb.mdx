## Usage

```tsx
import { AsciiOrb } from "@/components/asciicn/ascii-orb";

export function Assistant({ talking }: { talking: boolean }) {
  return (
    <AsciiOrb
      state={talking ? "speaking" : "listening"}
      audio="mic"
      className="aspect-square w-64"
    />
  );
}
```

`state` sets what the orb is doing, and changes cross-fade over about half a second.

- `idle` breathes slowly, its outline drifting.
- `listening` draws rings inwards and swells with the input level.
- `speaking` pulses four lobes with the bass and sends waves outwards.

Without `audio`, the listening and speaking states move on a soft built-in rhythm. Pass `audio="mic"` to follow the microphone, a `<audio>` element or `MediaStream` to follow your text-to-speech, or bands you already analyse with `useAudioBands` from `@/lib/ascii/audio`. `"synth"` is a silent demo tone that needs no permission.

The light and the orb lean gently towards the pointer. Set `lean={0}` to keep them still.

## Notes

- It is announced as an image labelled "Voice assistant" and its state. Pass `aria-label` for your own wording, and announce state changes in text as well, since the motion alone is not enough.
- The microphone needs a secure context (`https://` or `localhost`) and a permission prompt. Ask for it from a button press, not on page load.
- Under reduced motion it draws one still frame and does not lean.
- It draws at up to 60 fps and pauses offscreen and in hidden tabs. Samples far outside the halo are skipped.
