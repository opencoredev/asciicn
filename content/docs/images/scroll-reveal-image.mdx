## Usage

```tsx
import { ScrollRevealImage } from "@/components/asciicn/scroll-reveal-image";

export function Chapter() {
  return (
    <ScrollRevealImage
      src="/photos/summit.jpg"
      alt="The summit ridge at first light"
      className="aspect-[3/2] w-full"
    />
  );
}
```

The image moves through `stages` as it travels up the screen. Each stage is a cell size and a charset. The default runs from 28px ANSI blocks through classic ramps to 7px Braille. Within a stage, glyphs grow from sparse to full before the next one takes over. With `to="photo"`, the original file fades in over the last part of the scroll.

Scroll back up and it coarsens again. Progress is worked out from the image's position, not from time, so it always matches where the reader is.

Set `charset` to keep one charset at every stage and only change the cell size. Inside a scrolling panel instead of the page, pass that panel as `scrollRoot`.

## Notes

- With reduced motion, the image shows its last stage straight away, and the photo when `to="photo"`.
- It draws only while the reader scrolls and rests in between. Each stage change measures a new grid, so keep `stages` to a handful.
- The wrapper is announced as an image labelled with `alt`.
